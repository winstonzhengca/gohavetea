埃德蒙顿茶地图

茶在埃德蒙顿并不只生活在茶馆里。它也出现在河谷植物、家庭花园、华埠历史、社区活动、亚洲超市货架、奶茶柜台、餐馆、学生生活、保温杯、艺术项目与共享茶桌中。

这张地图不是商家排名，也不是完整名录，而是实体展览的空间延伸：它把地点与三张展桌中的故事连接起来。

地图图层

  • 植物与迁移——以 Edmonton Goji Map 为主要入口，介绍河谷与家庭花园中枸杞的公共历史。未经明确许可，不公开私人住宅地址或精确植物位置。
  • 华裔加拿大人历史——以区域层级介绍 Chinatown、Boyle Street 与 McCauley 的历史背景，不虚构所谓“第一家茶馆”的线性故事。
  • 茶空间——茶馆、餐馆、商店、社区组织与临时活动，只有在地址公开、资料可核实且与展览主题有关时才进入地图。
  • 奶茶与青年文化——使用街区集群或获许可的个人故事，而不试图列出全部店铺。
  • 本次展览——活动期间标注 Heritage Festival 展馆；日期、时间与地点以上线前主办方确认为准。
