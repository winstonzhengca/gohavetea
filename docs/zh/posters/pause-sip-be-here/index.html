“禅茶一味”是当代茶文化中常见的说法，把饮茶与禅修强调的专注联系起来。“一味”并不是说茶与佛教完全相同，而是提示我们：泡茶、奉茶与共饮这样的日常动作，也可能成为安住当下的练习。

历史说明

本展览把“禅茶一味”视为后世形成并不断流行的文化表达，而不是一条自古不变、能够概括所有佛教与茶之关系的教义。
