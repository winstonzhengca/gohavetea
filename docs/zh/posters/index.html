海报馆

这些海报本身就是展览的一部分，而不是事后追加的宣传品。书法、绘画、诗句、器物与埃德蒙顿地景共同承担策展工作。

海报馆分为三组：

  • 吃茶去：关于注意力的文字——策展短语、古典诗句、禅宗与道家的节奏。
  • 一叶多声：埃德蒙顿作为共享之桌——不同语言、迁移路线、街区生活与“和而不同”。
  • 植物在路上：桂花与枸杞——香气、植物迁移、记忆，以及“茶”与“代茶饮”之间的边界。

每张海报页面包括高清图、完整文字稿、历史背景、艺术家资料、策展解读、替代文字，以及在版权允许时提供的下载文件。

发布原则 公开海报馆只收录经过确认的最终作品与具有明确意义的最终版本。书法不完整、引文错误、使用了未经同意的装饰元素、或错误归属艺术家的草稿，应留在内部设计档案中，而不作为正式网上展品。
