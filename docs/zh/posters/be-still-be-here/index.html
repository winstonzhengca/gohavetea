English

静下来，在这里

致虚极，守静笃。

《道德经》第十六章

历史说明

这句话常被理解为：不要急于强制与控制，而是在变化之中保持观察。这里的“静”并非退出现实，也不等于消极不行动。

策展解读

海报把安静放回埃德蒙顿的移动、天气与公共生活之中。所谓“在这里”，就是意识到自己站在哪里、身边还有谁，以及我们多么容易迅速判断差异。注意力因此成为一种安静的责任。
