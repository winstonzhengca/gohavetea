桂花茶

花虽小，香气悠长。

桂子月中落，天香云外飘。

唐代；传统上归于宋之问《灵隐寺》

海报文字稿

干桂花可以单独浸泡，也可与绿茶、乌龙茶或红茶搭配。若不含茶树叶，更准确的英文名称是 floral infusion 或 tisane，尽管中文日常仍称之为“桂花茶”。

策展解读

海报从很小的材料出发，打开风景、记忆与命名。气味常常能够迅速穿越时间。“这种香气会把你带到哪里？”邀请观众分享个人记忆，却不把气味写成疗效。

说明 用于文化学习与讨论，不构成医疗建议。
