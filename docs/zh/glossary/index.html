茶词汇

四十个词条，分成四组，每条附一句公众解释与一个容易混淆之处。泡茶水温与方法见泡茶小贴士。

基础词汇

茶树 / Camellia sinensis
绿茶、白茶、黄茶、乌龙茶、红茶与黑茶背后唯一的植物物种。人们有时以为不同茶类来自不同植物，其实几乎都来自同一物种，只是采摘后的处理方式不同。
茶叶
茶树经采摘、加工前后的叶片。日常用语中“茶叶”既可指树上的鲜叶，也可指罐中的成品干茶，多数时候语境能说明是哪一种。
茶汤
茶叶遇水后产生的液体。中文和英文都可能把“茶”同时用于叶片与饮料，本词汇表在需要区分时特意使用“茶汤”或“茶叶”。
散茶
不装入茶包、整片或碎片状出售的茶叶，通常比茶包留出更多舒展空间，也在多次冲泡中呈现更丰富的香气与浓度变化。
袋泡茶
装有碎茶或茶末的小型透气袋，专为快速的单次冲泡设计。方便，但较碎的茶叶通常比散茶少一些层次。
茶器
用来制作与奉茶的器具：壶、杯、盘与工具。茶器不仅是装饰，其形状与材质会实际改变茶汤的味道与聚会的节奏。
盖碗
一种带盖的碗，用来冲泡与品饮，常见于许多中国茶传统。它是众多做法之一，而不是唯一“正确”的中国茶器——大杯与保温杯在日常生活中同样常见。
水壶
用来加热泡茶用水的器具。不同茶适合不同水温（见泡茶小贴士），因此能够控温的水壶比只能烧开的水壶更实用。
浸泡 / 冲泡
让茶（或其他植物）在热水中停留，使香气与味道释放到水中的过程。“浸泡”也可作名词，指浸泡后得到的饮品，尤其常用于非茶树植物。
草本浸泡饮 / tisane
以茶树以外的植物浸泡制成的饮料，例如桂花或枸杞。植物学上它不是“茶”，但中文与英文日常仍常把它称为茶。

制茶工艺

采摘
从茶树上摘取鲜叶与芽的动作。选择怎样的鲜叶——一芽两叶，还是更粗放的采摘——在任何加工开始之前，就已经决定了成品茶的等级与风格。
萎凋
采摘后有控制地让叶片静置、失去部分水分并变软的过程。听起来被动，实际上判断萎凋是否“到位”，需要经验而非固定时长。
杀青
通过干热或蒸汽加热，停止导致氧化的酶活性的一道工序。它把茶在某一时刻的颜色与特性“固定”下来，这也是绿茶保持绿色、红茶不再是绿色的原因。
揉捻 / 做形
以手工或机器揉压萎凋后的叶片，破坏细胞壁、释放香气物质，并塑出茶叶最终的形状——卷曲、条索或团状——同时也影响后续冲泡的表现。
氧化
叶片内含物质与氧气发生反应、经揉捻与时间、湿度调控而改变颜色与香气的化学过程，与微生物发酵是不同的机制，二者经常被混淆。
干燥
最后去除水分、使茶叶便于存放与运输的工序。干燥的方式与火候会影响香气，若处理不当，也可能掩盖或损害此前每一道工序的成果。
焙火
干燥之后有时会追加的加热处理，能带来更深、更烘烤或更果香的风味，常见于部分乌龙茶。这是一种收尾选择，并非每款茶都会经历。
窨制
把茶与花香或其他香气原料混合或反复接触，如桂花茶或茉莉花茶。窨制既可以通过反复接触鲜花，也可以通过混入干花完成。
微生物转化 / 发酵
由微生物在时间中推动的变化，在部分黑茶及其他陈化或渥堆工艺中十分重要。它常被笼统称为“发酵”，但在化学机制上与红茶的氧化并不相同。
陈化
茶叶加工完成后持续、通常缓慢发生的变化，有时是刻意为之（如部分黑茶与普洱），有时只是存放的结果。并非所有茶都适合陈放——许多茶更适合趁新鲜饮用。

茶与社会生活

功夫茶
强调技艺、专注与在小型器具中反复短时冲泡的泡茶方式，具有特定的地域与社会历史。它是重要的中国茶实践之一，而不是唯一正确的方式。
待客
用茶欢迎他人的社会性工作：购买茶叶、烧水、清洗器具、服务，并留意客人是否舒适。待客是一种实践，不会自动发生。
日常照护
奉茶、记住一个人的偏好、探望他人等重复的小小举动，是人们日常互相关照的方式。它与养生语言有所重叠，却不等同于医疗治疗。
活态传统
人们不断更新、而非原样冻结保存的知识与实践。称某事物为“活态传统”，是提醒今天的制茶者仍在积极塑造它，而不只是重复过去。
正宗 / 真实性
声称某种做法、物件或味道代表“真正的”或“原初的”版本。本展览把正宗视为需要追问的问题——谁有权决定，为什么——而不是它授予某一种做法的标签。
服务劳动
准备、解释、清洁、排班与服务，使一杯茶（或一杯奶茶）从原料变成顾客手中饮品的工作。它常常因为做得好而变得不被看见。
定制
让顾客可以选择茶底、糖度、冰量、配料等组件，而不是接受一杯固定饮品的系统。定制感觉很个人化，实际却依赖柜台后标准化的原料与流程。
公共人类学
面向更广泛公众、而不只是学术读者进行对话的人类学实践，常通过展览、写作、教学或艺术展开。这个网站与它所记录的展览，都是这种取径的例子。
策展解读
策展人对某件物品、作品或主题提出的一种有依据的理解，而不是终极、中立的事实。本展览清楚标示策展解读，让观众能把它与历史记录区分开。
和而不同
出自《论语》的古典短语，在这里用来说明人们可以共享一张桌子、一座城市或一种文化，却不必因此变得一样。它不意味着分歧或差异应被抹平。

植物与饮料

枸杞
在亚洲有悠久使用历史的结果灌木，自19世纪90年代起也在埃德蒙顿河谷与家庭花园中拥有重要而仍在延续的生活史。它是一株植物，也是一组关系，而不只是包装袋里的“超级食物”。
桂花
香气浓郁的小花，是江南地区重要的时令食材。可用来窨制茶叶，也可单独浸泡——参见下方“桂花茶”的区分。
桂花茶
一个日常名称，既可能指用桂花窨制或调配的茶叶，也可能指主要由花朵本身泡成、不含茶叶的浸泡饮。名称本身不能告诉你是哪一种，需要询问或查看配料。
糖桂花
以糖或糖浆腌渍保存的桂花，用于江南地区的甜品、饮品与烹饪。它既是厨房食材，也与茶饮相关。
珍珠奶茶
1980年代在台湾发展起来的饮料，通常由茶、奶或奶精、糖、冰与珍珠等配料组合而成。确切起源在两家台湾茶馆之间仍有争议，本展览不裁定此争议。
茶底
定制饮品中的茶叶部分——如红茶、绿茶、乌龙茶或果茶，在加入奶、糖与配料之前先行选定。它是奶茶订单中唯一在植物学意义上真正属于“茶”的部分。
配料 / 小料
定制饮品中加入的原料——如珍珠、仙草冻、布丁——在改变口感的同时也改变风味。配料需要单独准备，也需要各自的保存与制作时间。
甜度
菜单选项，通常以百分比（0—100%）表示，让顾客决定饮品中加入多少糖浆。它是一套让大量口味选择显得容易点单的系统。
冰量
控制冷饮中冰块多少的菜单选项，与甜度或茶浓度无关——选择“少冰”通常意味着口感更浓、稀释更少，而不只是温度不同。
珍珠 / 木薯粉圆
以木薯淀粉制成的Q弹圆球，是珍珠奶茶名称的由来。珍珠必须经过烹煮、保温，并在数小时内使用，这正是一杯“简单”饮品背后被隐藏的劳动之一。
