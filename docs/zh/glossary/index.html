词汇表

茶树 Camellia sinensis
绿茶、白茶、黄茶、乌龙茶、红茶与黑茶等的植物来源。
茶
既可以指植物、加工后的叶片、冲泡饮料、商品，也可指一组社会实践，必须结合语境理解。
草本浸泡饮 / tisane
以茶树以外的植物浸泡制成的饮料。日常中文仍可能称它为“茶”。
功夫茶
强调技艺、注意力、反复冲泡并具有具体区域与社会历史的泡茶实践，不是唯一的中国泡茶方式。
萎凋
采摘后有控制地让叶片失去部分水分。
杀青
通过加热减缓酶活性，并影响后续转化。
氧化
影响颜色、香气与味道的化学变化，不等同于微生物发酵。
微生物转化 / 发酵
微生物参与的变化，在部分黑茶等工艺中非常重要。
珍珠奶茶
1980年代在台湾发展起来的饮料，常由茶、奶或奶精、糖、冰与珍珠等配料组合而成。
定制
允许顾客选择茶底、甜度、冰量与配料的系统。
服务劳动
准备、解释、清洁、排班、服务与处理顾客互动的工作。
枸杞
具有亚洲历史、并在埃德蒙顿河谷与家庭花园中拥有重要生活史的结果灌木。
日常照护
喂养、奉茶、记住、探望并为他人留出时间的重复实践，不等于医疗治疗。
活态传统
由人持续更新、而不是原样冻结保存的知识与实践。
公共人类学
通过展览、写作、教学、艺术与社区合作，与更广泛公众开展对话的人类学实践。
