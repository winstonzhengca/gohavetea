三张展桌

展览在空间上分成三张桌子，却只讲述一个相互连接的故事。每张桌子都从一个动作开始：转化、扎根或重组。文化不是被静态摆放出来的，而是在实践中被做出来的。

你不必按照固定顺序参观。从一片叶子、一株植物，或一只吸引你的杯子开始即可。

中国茶——转化

一株植物，多种工艺，多种传统。

养生与枸杞——扎根

植物、家庭知识、迁移与埃德蒙顿的日常照护。

珍珠奶茶——重组

台湾的饮品创造、全球流动、定制与劳动。
