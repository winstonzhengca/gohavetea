养生与枸杞

快速浏览

植物会跟着人移动。自19世纪90年代华人来到埃德蒙顿以后，枸杞便在本地河谷与家庭花园中生长。

这里的“养生”不是治愈疾病的承诺，而是一段关于迁移、家庭知识、适应、贸易、待客与日常照护的故事。

主要研究贡献者 关咏霏。本节关于埃德蒙顿枸杞的内容，主要建立在关咏霏的研究与公共项目之上。他创作的 Edmonton Goji Map 从河谷植物、社区历史、艺术与“家”的变化出发，记录枸杞如何在这座城市扎根。
浏览 Edmonton Goji Map

一株移动的植物

艺术家与研究者关咏霏的《埃德蒙顿枸杞生活史》与 Edmonton Goji Map，把植物、华裔加拿大人的历史、家庭花园、邻里知识与公共艺术连接起来。在埃德蒙顿，枸杞可以是河谷植物、后院灌木、邻里交换的幼苗、关于长辈的记忆，或当代艺术的研究对象——不只是包装袋里的“超级食物”。

植物扎下两种根

植物在土壤中扎根，也会在记忆中扎根。迁移者携带种子、味觉、名称与期待进入新环境；气候改变什么能够存活，也改变它的使用方式。邻居交换枝条，孩子可能先认识包装里的枸杞干，再认识真实灌木。埃德蒙顿枸杞并不是一个简单的“文化保存”故事：植物在适应，人也在适应，意义会改变，却没有因此失去更长的迁移路线。

照护不是疗效承诺

展桌也介绍花草浸泡饮与加拿大/北美花旗参，说明流动并非只有“亚洲到北美”一个方向。展览既不把家庭经验说成万能知识，也不把专业和科学知识当成唯一声音——它关心不同权威如何在日常的一杯饮料中相遇，同时也明确哪些健康问题必须交给合资格的医疗专业人士。

教育用途说明 本页面分享文化历史与社区实践，不提供医疗建议或治疗推荐。草本与食物可能引发过敏或与药物相互作用；如有个人健康问题，请咨询合资格的医疗专业人员。

桂花：属于季节的香气

桂花在江南地区长期以来都是重要的时令食材。花虽小，香气却很鲜明，人们用它窨制或调配桂花茶，也会制作糖桂花、甜品和季节饮品。

日常所说的“桂花茶”，既可能是加入桂花的茶叶，也可能是以桂花为主的浸泡饮。名称不一定完全按照植物学分类。本次展桌也会展示桂花与桂花茶，让观众从香气出发，想一想季节、地方与记忆如何相连。

桂子月中落，天香云外飘。

传统上归于宋之问《灵隐寺》（唐代）

展桌现场

枸杞枝叶、干果、地图、花草浸泡饮与社区实践卡，把地方植物与跨越地域的记忆连接起来。有些杯中包含真正的茶树叶，有些则更适合称为草本浸泡饮或 tisane；中文日常生活仍可能把二者都称为“茶”。
