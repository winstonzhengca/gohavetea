关于展览

这是一项为 Edmonton Heritage Festival 策划的小型、可移动的公共人类学展览。它从人们熟悉的东西开始：茶叶、茶杯、枸杞、奶茶菜单、贴纸、书法和绘画；但它并不停留在“这是什么”的说明上，而是继续追问这些物件承载了怎样的历史与关系。

本展览无意概括所谓“中国茶文化全貌”。它只沿着三条具体路径前进。第一张桌子讨论制茶者如何把同一株植物转化为多种茶；第二张桌子以埃德蒙顿枸杞为中心，讨论植物、迁移与照护；第三张桌子从1980年代台湾的珍珠奶茶出发，连接侨民生活、连锁加盟、社交媒体与本地青年文化。

三张桌子共同说明：文化不是一份被密封保存的遗产，而是在迁移、劳动、适应、分歧与日常分享中不断被重新做出来的。

为什么在埃德蒙顿讲这些故事？

埃德蒙顿不只是一个展示外来文化的地点，它本身就在故事之中。

枸杞在本地河谷与家庭花园中生长已有数代人的历史；茶馆与奶茶店不断在不同语言和街区之间翻译味觉；漫长冬季、明亮夏日、移民、求学、工作与家庭生活，也会改变人们在什么时候、什么地方、用什么方式做一杯茶。因此，本展览关注的不是茶文化如何被原样保存，而是它如何在埃德蒙顿继续生活并发生变化。

民俗节中的公共人类学

公共人类学关心的是：研究如何成为对话，而不是单向讲解。民俗节的观众可能只停留十秒，也可能交谈十分钟。因此，每张桌子都从一个短标题和一个动作开始，再由物件、互动和二维码引向更深的阅读。

我们并不考查观众是否掌握“正确知识”，而是邀请大家看见关系：叶子与劳动、植物与迁移、菜单与服务、艺术与记忆、差异与待客之道。

一项展览，三个入口

无论从哪里进入：

  • 转化：一株植物为什么会成为多种茶？
  • 扎根：植物怎样成为一座新城市及其记忆的一部分？
  • 重组：一杯台湾饮料如何成为全球可定制的味觉语言？

最后都会回到同一个问题：当茶在路上，究竟什么也随之流动？

关于证据、措辞与照护

本展览区分传说、商业自述、社区知识、研究发现与策展解释。珍珠奶茶的历史明确标示台湾；中国茶不被描述为只有一种“正宗”形式；养生不被改写为治病承诺；艺术家、社区项目与研究者的名字和作品被放在相应材料旁边，而不是藏在页面末尾。
